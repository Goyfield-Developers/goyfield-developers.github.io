# Prologue

## Goyfield API

Goyfield does not have an official API. However, this mock API is acts similarly as an "API". 
It retrieves data from Goyfield and stores it in a structured JSON format. A full breakdown of how it works can be found [here](http://127.0.0.1:5500/main.html#api-mechanism/how-it-works).
This mock API is can be used for Discord or Telegram.

## Mock API
The short answer: A mock API is a simulated version of a real API, used primarily for testing and development.

The slightly longer answer: The mock API mimics the behavior of the actual API by providing realistic responses to requests, 
which enables developers to validate their code under real-world-like conditions even when the actual API is unavailable. 
Mock APIs can be locally hosted or on the network, depending on the requirements of the unit or integration tests being conducted.

[Source: WireMock](https://www.wiremock.io/glossary/mock-api)

## APIs
The API below will provide detailed explantion about every data's role. However it's mostly repetitive, don't waste your time here.


### Basic Headhunting
```json
{
  "Basic Headhunting": {
    "Total Users": 3341,
    "Total Pulls": 387223,
    "Oroberyl Spent": 193611500,
    "6-Star": {
      "Rate": "1.571%",
      "Count": 6083,
      "Median Pity": 62,
      "Won": null
    },
    "5-Star": {
      "Rate": "13.359%",
      "Count": 51728
    }

 ...
```
```
https://api.goyfield-developers.workers.dev/basic-headhunting
```

The permanent standard banner. Returns pull data from all users.

- Total Users
- Total Pulls
- Oroberyl Spent
- 6-Star Rate, Count, and Median Pity
- 5-Star Rate and Count
