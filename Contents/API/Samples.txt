# Samples

## Discord.js Examples

This is the very basic script that you can use for Discord bot. This script lets bot fetches data from basic headhunting api and 
send the data to the perform with reply messeage

index.js
```javascript
// This is a very basic Discord bot script.
// When a user types "headhunting", the bot fetches data from the Basic Headhunting API and replies with the results.

const { Client, GatewayIntentBits } = require("discord.js");

// Runs necessary permissions to read and receive messages
const client = new Client({
  intents: [
    GatewayIntentBits.Guilds,         // Access to servers
    GatewayIntentBits.GuildMessages,  // Access to messages
    GatewayIntentBits.MessageContent  // Access to read message content
  ]
});

// Runs once when the bot successfully logs in
client.once("ready", () => {
  console.log(`Logged in as ${client.user.tag}`);
});

// Runs every time someone sends a message
client.on("messageCreate", async (msg) => {
  if (msg.author.bot) return;                  // Ignore other bots
  if (msg.content !== "headhunting") return;  // Only respond to ".headhunting"

  try {
    // Fetch data from the API
    const response = await fetch("https://goyfield-api.betwo.workers.dev/basic-headhunting");
    const json = await response.json();
    const data = json["Basic Headhunting"];

    // Store each value in a variable 
    const users    = data["Total Users"].toLocaleString();
    const pulls    = data["Total Pulls"].toLocaleString();
    const oro      = data["Oroberyl Spent"].toLocaleString();
    const sixRate  = data["6-Star"].Rate;
    const sixCount = data["6-Star"].Count.toLocaleString();
    const sixPity  = data["6-Star"]["Median Pity"];
    const fiveRate  = data["5-Star"].Rate;
    const fiveCount = data["5-Star"].Count.toLocaleString();

    // Reply to the user with the data
    await msg.reply(
      `Users: ${users}\n` +
      `Pulls: ${pulls}\n` +
      `Oroberyl: ${oro}\n` +
      `6 Stars: ${sixRate} (${sixCount}) | Pity: ${sixPity}\n` +
      `5 Stars: ${fiveRate} (${fiveCount})`
    );
  } catch (err) {
    console.error(err);
    await msg.reply("Failed to fetch data."); // Reply if something goes wrong
  }
});

// Log the bot in using the token
client.login("Your Token Here");
```
This is a very basic Discord bot script that fetches data from the Basic Headhunting API and sends it back as a reply message.
The bot starts by importing Client and GatewayIntentBits from the discord.js library. 
Client is the bot itself, and GatewayIntentBits is the permissions the bot needs to function, and in this case, the intents are access to servers, messages, and read message content.
Once the bot successfully logs in, it prints a confirmation message in the console so you know it's running.
When a user types "headhunting", the bot fetches data from the API and stores in memory as variables and in this case the variables that stores it should be
 total users, pulls, oroberyl spent, and the 6-star and 5-star rates. 
The bot then reads the variables and send the reply.
If anything goes wrong during the fetch, like the API being down, it replies with "Failed to fetch data." to prevent crashing.
